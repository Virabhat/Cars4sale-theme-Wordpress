# 🚗 Cars4Sale — ธีม WordPress สำหรับเว็บไซต์รถมือสอง

Cars4Sale เป็น **Custom WordPress Theme สำหรับเว็บไซต์เต็นท์รถมือสอง** พัฒนาขึ้นเพื่อแสดงรถที่ร้านจำหน่าย ให้ลูกค้าค้นหารถ ดูรูปภาพและรายละเอียด ประเมินค่างวดเบื้องต้น และติดต่อร้านผ่านโทรศัพท์หรือ LINE

รูปแบบของเว็บไซต์เป็น **แคตตาล็อกรถออนไลน์พร้อมช่องทางติดต่อร้าน** การซื้อขาย การนัดหมาย และการจัดไฟแนนซ์ยังดำเนินการผ่านการติดต่อร้าน ไม่ได้มีขั้นตอนทำรายการเหล่านี้ภายในเว็บไซต์

> 📝 เอกสารนี้อธิบายจากโค้ดภายในโฟลเดอร์ธีม ยังไม่ได้ยืนยันการตั้งค่าปลั๊กอิน ฐานข้อมูล หรือผลการทำงานบนเว็บไซต์จริง

## 🎯 วัตถุประสงค์ของระบบ

### 🏠 1. หน้าแรกและรายการรถ

ไฟล์หลัก: [front-page.php](front-page.php)

- แสดงแบนเนอร์แนะนำ Cars4Sale พร้อมข้อความประชาสัมพันธ์
- ดึงรายการที่เผยแพร่แล้วจากชนิดข้อมูล `car` ด้วย `WP_Query`
- แสดงรถสูงสุด **12 คันต่อการแสดงผล** โดยยังไม่มีระบบแบ่งหน้า
- การ์ดรถแต่ละใบแสดงรูป ชื่อ ราคา ปีรถ เลขไมล์ และประเภทเชื้อเพลิง
- คลิกชื่อหรือรูปเพื่อเปิดหน้ารายละเอียดรถ
- แสดงรูปสำรองจากบริการภายนอกเมื่อไม่มีรูปประจำรายการ
- มีปุ่มโทรสอบถามบนการ์ดรถ
- แสดงส่วน “ทำไมต้องเลือกเรา?” และขั้นตอนการใช้บริการ

### 🔍 2. ค้นหาและกรองรถ

แบบฟอร์มส่งข้อมูลด้วยวิธี `GET` และโหลดรายการผลลัพธ์ใหม่เมื่อกดค้นหา

| ตัวกรอง | วิธีทำงาน |
| --- | --- |
| คำค้น `s_keyword` | ส่งเข้าเงื่อนไข `s` ของ WordPress เพื่อค้นหาในรายการรถ ไม่ได้จำกัดเฉพาะฟิลด์ชื่อรุ่น |
| เชื้อเพลิง `s_fuel` | กรองข้อมูลจากฟิลด์ `fuel_type` ด้วย `meta_query` และเงื่อนไข `LIKE` |
| ล้างการค้นหา | กลับหน้าแรกโดยไม่มีค่าตัวกรอง |

ประเภทเชื้อเพลิงที่เลือกได้คือ **เบนซิน ดีเซล ไฮบริด และไฟฟ้า (EV)** สามารถใช้คำค้นร่วมกับตัวกรองเชื้อเพลิงได้ และมีข้อความแจ้งเมื่อไม่พบรถที่ตรงกับเงื่อนไข

### 🏷️ 3. แสดงสถานะรถ

หน้าแรกอ่านสถานะจากฟิลด์ `car_status`

| ค่าที่จัดเก็บ | ข้อความที่แสดง | รูปแบบ |
| --- | --- | --- |
| `available` | พร้อมขาย | ป้ายสีเขียว |
| `reserved` | ติดจอง | ป้ายสีส้ม |
| `sold` | ขายแล้ว | ป้ายสีเทา พร้อมลดสีและความเข้มของรูป |

หากไม่มีค่าสถานะ โค้ดกำหนดค่าเริ่มต้นเป็น `available` รถที่ติดจองหรือขายแล้วยังคงแสดงอยู่ในรายการ เพราะยังไม่มีเงื่อนไขตัดรายการเหล่านี้ออก

> 💡 ส่วนนี้เป็นการแสดงสถานะจากข้อมูลที่บันทึกไว้ ยังไม่มีระบบให้ลูกค้ากดจองหรือเปลี่ยนสถานะอัตโนมัติ และหน้ารายละเอียดรถยังไม่ได้แสดงสถานะจากฟิลด์นี้

### 🚘 4. หน้ารายละเอียดรถ

ไฟล์หลัก: [single-car.php](single-car.php)

แสดงชื่อรถ ราคา และข้อมูลต่อไปนี้จาก ACF:

- 📅 ปีรถ
- 🛣️ เลขไมล์
- ⛽ ประเภทเชื้อเพลิง
- ⚙️ เครื่องยนต์
- 🕹️ ระบบเกียร์

ข้อมูลปี เลขไมล์ และเชื้อเพลิงที่ว่างจะแสดง `-` ส่วนเครื่องยนต์ เกียร์ และสีมีค่าแสดงสำรองเป็น `2.0L`, `Automatic` และ `Standard` ตามลำดับ

ป้าย `Grade A Condition` เป็นข้อความที่กำหนดไว้ในเทมเพลต ไม่ได้อ่านจากผลการตรวจสภาพของรถแต่ละคัน และเทมเพลตนี้ยังไม่ได้เรียกแสดงเนื้อหาหลักด้วย `the_content()`

### 🧮 6. คำนวณค่างวดเบื้องต้น

อยู่ภายในหน้ารายละเอียดรถ และคำนวณใหม่ทันทีเมื่อเปลี่ยนค่า

| รายการ | ตัวเลือกหรือค่าเริ่มต้น |
| --- | --- |
| เงินดาวน์ | 0%, 10%, 15%, 20%, 25%, 30% — เริ่มต้น 20% |
| ระยะเวลาผ่อน | 36, 48, 60, 72, 84 เดือน — เริ่มต้น 60 เดือน |
| ดอกเบี้ยต่อปี | เริ่มต้น 4.5% โดยช่องกรอกระบุช่วง 1–15% |
| ผลลัพธ์ | ค่างวดโดยประมาณต่อเดือน ปัดเป็นจำนวนเต็มและใส่เครื่องหมายคั่นหลักพัน |

สูตรที่โค้ดใช้เป็นการคิดดอกเบี้ยแบบคงที่จากยอดจัด:

```text
เงินดาวน์ = ราคารถ × เปอร์เซ็นต์ดาวน์ ÷ 100
ยอดจัด = ราคารถ − เงินดาวน์
ดอกเบี้ยรวม = ยอดจัด × (ดอกเบี้ยต่อปี ÷ 100) × (จำนวนเดือน ÷ 12)
ค่างวดต่อเดือน = ((ยอดจัด + ดอกเบี้ยรวม) ÷ จำนวนเดือน) × 1.07
```

ตัวคูณ `1.07` เป็นการบวก VAT 7% ตามที่โค้ดปัจจุบันกำหนด สูตรนี้เป็นเพียงการอธิบายการทำงานของโปรแกรม ไม่ได้ยืนยันเงื่อนไขของผู้ให้บริการไฟแนนซ์

โค้ดแปลงราคาด้วยการลบอักขระที่ไม่ใช่ตัวเลข เช่น `฿890,000` เป็น `890000` หากไม่มีราคาที่ใช้ได้จะใช้ **500,000 บาท** เป็นค่าคำนวณสำรอง จึงควรบันทึกราคาให้ครบและหลีกเลี่ยงราคาที่มีทศนิยมหรือข้อความย่อ เช่น `8.9 แสน`

ยังไม่มีแบบฟอร์มบันทึกผู้สนใจ ระบบแชทภายในเว็บ หรือระบบนัดหมาย ปุ่มทดลองขับในส่วนท้ายเว็บเป็นลิงก์โทรศัพท์

`functions.php` โหลด `style.css` และฟอนต์ Prompt เป็นส่วนกลาง จากนั้นเลือกโหลด CSS รายหน้าตามเงื่อนไขของ WordPress:

| เงื่อนไข | ไฟล์ที่โหลดเพิ่มเติม |
| --- | --- |
| `is_front_page()` | `css/front-page.css` |
| `is_singular('car')` | `css/single-car.css` |
| ใช้เทมเพลต `page-about.php` หรือเป็นหน้า `about` | `css/about.css` |

## 🚀 แนวทางติดตั้งและเตรียมใช้งาน

1. เตรียมเว็บไซต์ WordPress ที่ทำงานได้
2. วางโฟลเดอร์ `cars4sale` ภายใน `wp-content/themes/`
3. เปิดใช้งานธีม **Cars 4 Sale** ในหน้าจัดการธีม
4. ติดตั้งและเปิดใช้งาน ACF เนื่องจากเทมเพลตเรียก `get_field()` โดยตรง
5. ตรวจสอบหรือสร้างชนิดข้อมูล `car` ให้เปิดดูรายการแต่ละคันได้ และรองรับชื่อรถกับ Featured Image
6. ตรวจสอบการเปิดใช้ Featured Image ทั้งระดับธีมและชนิดข้อมูลรถ เพราะในธีมปัจจุบันยังไม่พบ `add_theme_support('post-thumbnails')`
7. สร้างชุดฟิลด์ ACF ตามตารางด้านบน และกำหนดให้แสดงกับชนิดข้อมูล `car`
8. เพิ่มและเผยแพร่รายการรถ พร้อมราคา รูปภาพ สเปก และสถานะ
9. สร้างหน้าเกี่ยวกับเรา โดยใช้ slug `about` และเลือกเทมเพลต `About Us Page` ตามการตั้งค่าที่ต้องการ
10. เปลี่ยนข้อมูลติดต่อ แผนที่ และข้อความประชาสัมพันธ์ให้ตรงกับร้านจริง
11. ทดสอบหน้าแรก การค้นหา หน้ารายละเอียด การสลับภาพ เครื่องคำนวณ และลิงก์ติดต่อทั้งบนคอมพิวเตอร์และมือถือ

ขั้นตอนนี้เป็นแนวทางตามโครงสร้างโค้ด ไม่ใช่การยืนยันว่าปลั๊กอินและข้อมูลในเว็บไซต์ปัจจุบันถูกตั้งค่าครบแล้ว
